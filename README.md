# Лабораторная работа 1. Общий элемент двух отсортированных массивов

Даны два отсортированных массива. Нужно вывести `True`, если у них есть хотя бы один общий элемент, и `False`, если общих элементов нет.

## Алгоритмы

M — размер меньшего массива, N — размер большего.

| Алгоритм                            | Функция        | Время         | Память |
| ------------------------------------------- | --------------------- | ------------------ | ------------ |
| Два указателя                   | `two_pointers`      | O(M + N)           | O(1)         |
| Бинарный поиск                 | `binary_steps`      | O(M · log N)      | O(1)         |
| Экспоненциальный поиск | `galloping_search`  | O(M · log(N / M)) | O(1)         |
| Двойной бинарный поиск  | `two_binary_search` | O(M · log(N / M)) | O(log M)     |

## Исследование

Все замеры проводятся на худшем случае: массивы без общих элементов, в первом только нечётные числа, во втором только чётные, и числа первого массива равномерно распределены по второму.

- **Массивы одинакового размера:** n от 10 до 1 000 000.
- **Разное соотношение размеров:** M = 1000 и M = 30, N = M, 2M, 4M, … примерно до 1 000 000.

Графики построены в логарифмическом масштабе по обеим осям.

## Результаты

| Соотношение размеров | Самый быстрый алгоритм |
| --------------------------------------- | ------------------------------------------ |
| N ≤ 4M                                 | Два указателя                  |
| N ≥ 8M                                 | Двойной бинарный поиск |
